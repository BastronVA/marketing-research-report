# Анализ аудитории
Сегментируй по ситуации, задаче, поведению, ценности и модели решения.

Для каждого сегмента опиши: контекст, триггер, JTBD, боли, выгоды, критерии, возражения, альтернативы, роли в решении, каналы, цикл покупки, ценность и приоритет.

JTBD: «Когда [ситуация], я хочу [действие], чтобы [результат]».

CJM: потребность → поиск → сравнение → обращение → согласование → покупка → результат → повторная покупка. Для каждого этапа: действия, вопросы, эмоции, барьеры, точки контакта и улучшения.

Value Proposition Canvas связывает задачи, боли и выгоды клиента с продуктами, устранителями боли и создателями выгоды.
