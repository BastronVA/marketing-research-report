# Страница управления проектами

Если основной PR конфликтует с текущим `main`, используйте эту отдельную страницу. Она добавлена новыми файлами и не переписывает существующий `index.html`.

После merge откройте:

```text
https://bastronva.github.io/marketing-research-report/project-manager.html?report=crp-2026-06-09
```

На странице будут:

- переключатель проектов;
- кнопка «Добавить новый проект»;
- загрузка четырёх файлов исследования:
  - `report-data.json`;
  - `research-report.md`;
  - `assumptions-and-gaps.md`;
  - `sources.csv`;
- отдельное хранение локальных проектов в `localStorage` браузера.

Важно: локально добавленные через браузер проекты не записываются обратно в GitHub. Чтобы проект был доступен всем, его нужно добавить в `reports/<report-id>/` и зарегистрировать в `reports/index.json`.
