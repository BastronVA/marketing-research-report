# Задача для Codex

Создай и поддерживай постоянный шаблон интерактивного маркетингового отчёта.

## Исходные файлы

- `index.html`
- `styles.css`
- `app.js`
- `report-data.schema.json`
- `sample-report-data.json`

## Принцип

Шаблон не генерируется заново под каждого клиента. Он читает `report-data.json`, соответствующий схеме, и отображает данные в едином дизайне.

Пользователь должен:

1. открыть `index.html`;
2. загрузить локальный `report-data.json`;
3. получить интерактивный отчёт;
4. распечатать его или сохранить в PDF.

## Обязательные элементы

- адаптивность;
- фиксированная навигация;
- KPI-карточки;
- TAM, SAM и SOM со сценариями;
- карточки трендов;
- таблица конкурентов;
- сегменты целевой аудитории;
- горизонтальный Customer Journey Map;
- Value Proposition Canvas;
- SWOT в сетке 2 на 2;
- Business Model Canvas из девяти блоков;
- план на 30, 60 и 90 дней;
- источники;
- скрытие пустых разделов;
- загрузка JSON;
- печатная версия.

## Ограничения

1. Не встраивать данные конкретного клиента в код.
2. Не менять поля JSON без обновления схемы, примера и рендерера.
3. Не добавлять внешние библиотеки без необходимости.
4. Не превращать отчёт в рекламный лендинг.
5. Не скрывать ограничения, допущения и источники.
6. Сохранять возможность локального запуска.
7. Проверять desktop, mobile и печать.

## Возможные улучшения

- переключатель сценариев;
- фильтр конкурентов;
- поиск по источникам;
- сворачивание длинных разделов;
- экспорт таблиц;
- CSS-переменные для брендирования;
- сохранение загруженного JSON в localStorage.

После каждого изменения проверь синтаксис, тестовые данные и перечисли изменённые файлы.
